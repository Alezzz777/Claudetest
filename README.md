# Контроль голосования

Мобильное web-приложение для контроля списка проголосовавших по ФИО
на нескольких участках с **серверным хранением** и **многопользовательским
доступом**. Изменения, сделанные одним пользователем, мгновенно появляются
у остальных (real-time через Server-Sent Events).

## Возможности

- Несколько **участков голосования** с независимыми списками сотрудников
- Загрузка списков ФИО — поштучно или вставкой из Excel
- Отметка проголосовавших в один тап + журнал «кто отметил» и время
- Счётчики в реальном времени: **всего / голосовали / осталось** и **% явки**
- Поиск по ФИО и фильтры (Все / Осталось / Голосовали)
- **Серверное хранение** в `data.json` (атомарная запись)
- **Многопользовательский режим**: несколько устройств работают одновременно,
  изменения синхронизируются через SSE
- **Страница сводки** (`/summary`) — итоги по всем участкам с прогресс-барами,
  таблицей и общей явкой
- Экспорт результатов в **CSV**
- Адаптивный UI под мобильный экран, поддержка PWA

## Запуск сервера

Требуется Node.js 18+.

```bash
npm start
# или:
node server.js
```

Переменные окружения:
- `PORT` (по умолчанию `3000`)
- `HOST` (по умолчанию `0.0.0.0`)

Затем откройте на телефонах в одной сети:
- Главная страница (отметки): `http://<IP-сервера>:3000/`
- Сводка по всем участкам: `http://<IP-сервера>:3000/summary`

## Использование

1. Откройте приложение на любом устройстве и нажмите **⚙**.
2. Укажите ваше имя (будет видно в журнале «кто отметил»).
3. Создайте участок (например, «Участок №1») и в редакторе вставьте список ФИО.
4. Закройте настройки и начинайте отмечать проголосовавших — тап по строке.
5. На втором телефоне можно открыть **📊** (Сводку) — она автоматически обновляется
   по мере поступления отметок с других устройств.
6. Через меню **⋮** доступны экспорт в CSV, сброс отметок и полное удаление данных.

## API

| Метод  | Путь                                              | Назначение                           |
|--------|---------------------------------------------------|--------------------------------------|
| GET    | `/api/state`                                      | Полное состояние                     |
| GET    | `/api/summary`                                    | Агрегированная сводка                |
| GET    | `/api/events`                                     | SSE-поток изменений                  |
| POST   | `/api/precincts`                                  | Создать участок                      |
| PUT    | `/api/precincts/:id`                              | Обновить (имя / список ФИО)          |
| DELETE | `/api/precincts/:id`                              | Удалить участок                      |
| POST   | `/api/precincts/:id/voters/:vid/vote`             | Переключить отметку                  |
| POST   | `/api/precincts/:id/reset`                        | Сбросить отметки участка             |
| POST   | `/api/reset-all`                                  | Удалить все данные                   |

## Структура

- `server.js` — HTTP-сервер на Node.js (без внешних зависимостей)
- `index.html` — основной интерфейс (отметка голосов)
- `summary.html` — страница сводки по всем участкам
- `manifest.json` — PWA-манифест
- `data.json` — хранилище (создаётся автоматически)
