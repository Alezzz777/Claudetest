# Контроль голосования

Мобильное web-приложение для контроля списка проголосовавших по ФИО на нескольких участках.

## Возможности

- Создание нескольких **участков голосования**
- Загрузка списков сотрудников (ФИО) — поштучно или вставкой из Excel
- Отметка проголосовавших в один тап
- Показатели в реальном времени: **всего / голосовали / осталось** и **процент явки**
- Поиск по ФИО и фильтры (Все / Осталось / Голосовали)
- Сохранение данных в браузере (localStorage) — работает офлайн
- Экспорт результатов в **CSV**
- Адаптивный UI, оптимизированный под мобильный экран
- Поддержка PWA (можно «Добавить на главный экран»)

## Запуск

Откройте `index.html` в любом современном браузере (Chrome, Safari, Firefox).

Для работы на нескольких устройствах разместите файлы на любом статическом
хостинге (GitHub Pages, Netlify, Nginx и т.п.):

```bash
# Локальный запуск, например:
python3 -m http.server 8080
# затем открыть http://<IP>:8080 с телефона в одной сети
```

## Использование

1. Нажмите **⚙** (шестерёнка) в шапке.
2. Создайте участок (например, «Участок №1»).
3. В редакторе участка вставьте список сотрудников — по одному ФИО на строку.
4. Закройте настройки и начинайте отмечать проголосовавших — тап по строке.
5. Сверху отображается счётчик и процент явки.
6. Через меню **⋮** можно экспортировать результаты в CSV или сбросить отметки.

## Структура

- `index.html` — всё приложение (HTML + CSS + JS)
- `manifest.json` — PWA-манифест
