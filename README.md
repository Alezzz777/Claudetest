# Tie Catalog

Мобильное web-приложение для домашней картотеки галстуков с AI-распознаванием на Claude vision.

## Возможности

- 📸 **Распознавание по фото** — Claude vision определяет узор, цвета, материал, оценивает ширину/длину и ориентировочную цену.
- 🗂 **Поиск в локальной базе** — если карточка похожа на уже сохранённую, приложение подскажет.
- 🧺 **Пакетная обработка** — фото с несколькими галстуками возвращает список с вероятными названиями (с уверенностью).
- 👔 **Подбор рубашки** — для любого галстука AI предложит 3–5 цветов рубашек для разных поводов.
- 🔁 **Подбор галстука по рубашке** — сфотографируйте рубашку, получите варианты из коллекции и общие рекомендации.
- 🧍 **Визуализация примерки** — упрощённая композиция: силуэт + цвет рубашки + ваше фото галстука сверху.

## Стек

- Next.js 15 (App Router, mobile-first PWA)
- PostgreSQL через Prisma (готов к Neon serverless)
- Claude vision (`@anthropic-ai/sdk`)
- Tailwind CSS

## Локальный запуск

```bash
cp .env.example .env
# заполните DATABASE_URL и ANTHROPIC_API_KEY
npm install
npx prisma migrate dev --name init
npm run dev
```

Откройте http://localhost:3000 в мобильном браузере (или включите device toolbar в DevTools).

## Деплой

**База:** создайте проект на [Neon](https://neon.tech), скопируйте connection string в `DATABASE_URL`.

**Приложение:** на [Render](https://render.com) — `New + → Web Service → Docker`, подключите репозиторий. Используется `render.yaml`. Задайте секреты:

- `DATABASE_URL` — Neon connection string
- `ANTHROPIC_API_KEY` — ключ Claude API
- `CLAUDE_MODEL` (опц.) — id модели, по умолчанию `claude-sonnet-4-6`

Миграции применяются автоматически на старте контейнера (`prisma migrate deploy`).

## Структура

```
src/
  app/
    api/
      ties/                # CRUD карточек
      photo/[id]           # отдача байтов фото
      photo/by-tie/[id]    # primary фото по tieId
      recognize/           # одиночное распознавание
      batch/               # пакетная обработка
      match/shirt-for-tie/ # подбор рубашки к галстуку
      match/tie-for-shirt/ # подбор галстука к рубашке
    add/                   # добавление по фото
    batch/                 # пакет
    match/                 # подбор по фото рубашки
    tie/[id]/              # карточка
  components/
  lib/
prisma/schema.prisma
```

## Что упрощено

- **Try-on** — это композиция (SVG-силуэт + ваш галстук поверх). Реальная generative-примерка
  (image-to-image) требует отдельной модели (Replicate / Stability) — заложен компонент `TryOn`, в который можно подменить генератор.
- **Хранение фото** — байты в Postgres (поле `bytea`). Удобно для самостоятельного хостинга. Для продакшна с большим объёмом замените на S3-совместимое хранилище.
- **Поиск в интернете** — параметры берутся из визуального анализа Claude (он опирается на знания о рынке), без отдельных скрейперов.
