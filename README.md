# Контроль голосования

Мобильное web-приложение для контроля списка проголосовавших по ФИО
на нескольких участках с **серверным хранением**, **ролевым доступом**
(администратор / пользователь) и **многопользовательским режимом**.
Каждый пользователь входит по персональной ссылке и видит только свои
участки; администратор видит все, отмечает голоса на любом участке
и управляет пользователями.

## Возможности

- **Пользователи и ссылки-токены**: администратор создаёт пользователей
  и выдаёт каждому персональную ссылку для входа. Токен сохраняется
  в браузере, ссылка действует до её перевыпуска.
- **Роли**:
  - *Пользователь* — видит и редактирует только свои участки.
  - *Администратор* — видит все участки, может назначать владельцев,
    отмечать голоса на любом участке, видит сводку и управляет пользователями.
- Несколько **участков голосования** с независимыми списками сотрудников
- Загрузка списков ФИО — поштучно или вставкой из Excel
- Отметка проголосовавших в один тап + журнал «кто отметил» и время
- Счётчики в реальном времени: **всего / голосовали / осталось** и **% явки**
- Поиск по ФИО и фильтры (Все / Осталось / Голосовали)
- **Серверное хранение** в `data.json` (атомарная запись)
- **Real-time синхронизация** между всеми устройствами через Server-Sent Events
- **Страница сводки** (`/summary`, админ) — итоги по всем участкам
- **Админ-панель** (`/admin`) — создание/удаление пользователей,
  переименование, выдача прав, перевыпуск ссылок
- **Импорт CSV**:
  - пользователей в админ-панели (с предпросмотром, пропуском дубликатов
    и выгрузкой готовых ссылок CSV-файлом);
  - сотрудников при редактировании участка (с опцией «добавить к существующим»).
  Разделитель (`,` / `;` / таб) определяется автоматически, кавычки и BOM
  поддерживаются.
- **Резервные копии в JSON** (только админ): отдельно для базы пользователей
  и для состояния голосования. Импорт в двух режимах: `merge` (дополнить) и
  `replace` (полная замена) — подходит для переноса между серверами и отката.
- Экспорт результатов в **CSV**
- Адаптивный UI под мобильный экран, поддержка PWA

## Запуск сервера

Требуется Node.js 18+.

```bash
npm start
# или:
node server.js
```

Переменные окружения:
- `PORT` (по умолчанию `3000`)
- `HOST` (по умолчанию `0.0.0.0`)
- `PUBLIC_URL` (например `https://voting.example.com`) — используется в
  ссылках для пользователей. Если не задан, берётся хост из заголовков
  запроса.

При первом запуске автоматически создаётся пользователь-администратор;
**ссылка для входа выводится в консоль и сохраняется в `admin-link.txt`**.
Сохраните её — это единственный способ войти как админ.

Страницы:
- Голосование: `/`
- Сводка (только админ): `/summary`
- Пользователи (только админ): `/admin`

## Использование

### Администратор

1. Откройте ссылку из консоли (`admin-link.txt`).
2. Перейдите в **👥 Пользователи** (`/admin`):
   - создайте пользователей, для каждого автоматически сгенерируется
     персональная ссылка — нажмите «📋» и отправьте её пользователю
     (мессенджер, e-mail, QR-код);
   - при необходимости перевыпустите ссылку, переименуйте или удалите
     пользователя.
3. Создавайте участки и в редакторе указывайте **владельца** — пользователь
   увидит этот участок у себя по своей ссылке.
4. **📊 Сводка** — общая явка и разбивка по всем участкам в реальном времени.
5. Админ может тапать имена на любом участке — отметка сохранится с подписью
   «Администратор».

### Импорт пользователей из CSV

В админ-панели нажмите **📂 Импорт CSV**.

Формат файла — одна строка на пользователя:

```csv
Иванов Иван Иванович
Петров Пётр Петрович;admin
"Сидорова, Анна Сергеевна";
```

- Первая колонка — имя.
- Вторая (необязательная) — роль: `admin` / `админ` / `1` → администратор.
- Разделитель — `,` / `;` / таб (определяется автоматически).
- Пустые строки и дубликаты по имени пропускаются.
- В кодировке UTF-8 (BOM поддерживается).

После создания откроется окно со списком созданных пользователей и
их ссылками. Каждую ссылку можно скопировать, а весь список —
скачать одним CSV (`Имя; Роль; Ссылка`) и разослать.

### Резервные копии (JSON)

В админ-панели секция **«Резервные копии»** содержит две независимые пары
кнопок:

- **База пользователей** — список аккаунтов с токенами и ролями.
  Используется для переноса доступов между серверами.
- **Состояние голосования** — все участки, списки ФИО, отметки и время
  с подписью «кто отметил». Это полный снимок данных голосования.

Каждый импорт открывает диалог с выбором режима:

- **Добавить** (`merge`) — существующие записи сохраняются, из файла
  добавляются только новые. Дубликаты пользователей определяются по `id`
  и по имени (без учёта регистра); участки-дубликаты получают новый `id`.
- **Заменить** (`replace`) — все существующие данные удаляются и заменяются
  содержимым файла. При замене базы пользователей **аккаунт текущего
  администратора всегда сохраняется**, чтобы не потерять доступ.

При импорте состояния, если `ownerId` участка из файла не существует на
текущем сервере, сервер пробует сопоставить владельца по `ownerName`,
иначе участок назначается текущему администратору (число переназначений
показывается в результате).

### Импорт сотрудников из CSV

В редакторе участка (⚙ → ✏️) кнопка **📂 Импорт CSV** загружает список ФИО
из файла. Если в файле несколько колонок — берётся первая. Чекбокс
**«добавить к существующим»** дозаписывает имена в конец текущего списка
(без него — заменяет полностью). После сохранения отметки голосования
сохраняются по совпадению ФИО.

### Пользователь

1. Откройте полученную от администратора ссылку (например,
   `https://voting.example.com/?token=...`). Токен сохранится в браузере,
   далее достаточно открывать `https://voting.example.com/`.
2. Видите только свои участки. По умолчанию можно создать собственный
   участок и загрузить список ФИО, либо администратор уже назначил вам участок.
3. Тапайте по строке, чтобы отметить голосующего. Сверху обновляется
   счётчик и процент явки.

## API

Все запросы (кроме `OPTIONS`) требуют `Authorization: Bearer <token>`
или `?token=<token>` (используется для SSE).

| Метод  | Путь                                              | Кто                | Назначение                  |
|--------|---------------------------------------------------|--------------------|-----------------------------|
| GET    | `/api/me`                                         | любой              | Текущий пользователь        |
| GET    | `/api/state`                                      | любой              | Свои участки (админ — все)  |
| GET    | `/api/summary`                                    | любой              | Сводка по доступным участкам|
| GET    | `/api/events`                                     | любой              | SSE-поток изменений         |
| GET    | `/api/users`                                      | админ              | Список пользователей        |
| POST   | `/api/users`                                      | админ              | Создать пользователя        |
| POST   | `/api/users/bulk`                                 | админ              | Импорт пользователей пачкой |
| GET    | `/api/export/users`                               | админ              | Экспорт базы пользователей (JSON) |
| POST   | `/api/import/users`                               | админ              | Импорт базы пользователей (`mode: merge\|replace`) |
| GET    | `/api/export/state`                               | админ              | Экспорт состояния голосования (JSON) |
| POST   | `/api/import/state`                               | админ              | Импорт состояния (`mode: merge\|replace`) |
| PUT    | `/api/users/:id`                                  | админ              | Имя / флаг админа           |
| POST   | `/api/users/:id/regenerate-token`                 | админ              | Новая ссылка                |
| DELETE | `/api/users/:id`                                  | админ              | Удалить пользователя        |
| POST   | `/api/precincts`                                  | любой              | Создать участок             |
| PUT    | `/api/precincts/:id`                              | владелец / админ   | Имя / список / владелец     |
| DELETE | `/api/precincts/:id`                              | владелец / админ   | Удалить участок             |
| POST   | `/api/precincts/:id/voters/:vid/vote`             | владелец / админ   | Переключить отметку         |
| POST   | `/api/precincts/:id/reset`                        | владелец / админ   | Сбросить отметки участка    |
| POST   | `/api/reset-all`                                  | админ              | Удалить все участки         |

## Структура

- `server.js` — HTTP-сервер на Node.js (без внешних зависимостей)
- `index.html` — основной интерфейс (отметка голосов)
- `summary.html` — страница сводки по всем участкам (админ)
- `admin.html` — управление пользователями (админ)
- `manifest.json` — PWA-манифест
- `data.json` — хранилище (создаётся автоматически)
- `admin-link.txt` — ссылка администратора при первом запуске
